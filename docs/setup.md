# Setup Neovim

## Where does Neovim configuration live?

```vim
:echo stdpath('config')
```

### Change the configuration directory

```bash
NVIM_APPNAME=<New Nvim Dir> neovim
```

```bash
NVIM_APPNAME=$HOME/dev/personal/projects/nvim nvim
```

see 3.7 at https://wiki.archlinux.org/title/neovim
